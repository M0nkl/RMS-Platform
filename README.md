# RMS Platform — кликабельный прототип

Демонстрационный интерфейс для управления сервисными роботами. Используются только фронтенд и демонстрационные данные; настоящие роботы, серверная база данных и корпоративные API не подключены.

## Требования

- Node.js LTS
- VS Code или другой редактор
- Chrome, Edge или Safari

## Запуск на Windows

Откройте папку проекта в VS Code, выберите **Terminal → New Terminal** и выполните:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173/`.

## Запуск на macOS

Установите Node.js LTS и VS Code, скопируйте папку проекта на Mac, откройте её в VS Code и выберите **Terminal → New Terminal**:

```bash
npm install
npm run dev
```

Откройте адрес Vite, обычно `http://localhost:5173/`.

Для production-сборки на любой системе:

```bash
npm run build
```

Готовые статические файлы появятся в `dist/`.

## Публикация через GitHub Pages

После отправки этого проекта в GitHub откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации. Workflow в `.github/workflows/deploy.yml` автоматически соберёт и опубликует сайт при отправке изменений в ветку `main`. Ссылка появится на странице **Settings → Pages**.

## Демонстрационный вход и возможности

На странице входа используйте любые непустые логин и пароль — это макет, не настоящая авторизация. Доступны обзор, карта этажей, каталог роботов, задачи, маршруты, аналитика, инфраструктура, интеграции, сотрудники и роли, уведомления, помощник, журнал действий и настройки.

Задачи и некоторые настройки сохраняются в `localStorage` текущего браузера. Не вводите настоящие пароли и персональные данные.
